# 扩展 Azure TTS 语音选项和修复语速控制

## Why
随着用户对语音合成质量要求的提升和Azure TTS服务的发展，需要提供更丰富的语音选择和更好的语速控制体验。当前系统支持的语音数量有限，限制了用户的使用场景和个性化需求。通过扩展语音选项，可以显著提升用户的语音合成体验，满足不同内容类型和风格的需求。

## 概述
本提案旨在扩展 Azure TTS 插件支持的语音选项，添加更多中文语音（如 yunxi、xiaochen 等），并修复语速控制功能，确保语速参数能够正确应用。

## 背景
当前 Azure TTS 插件仅支持三种中文语音（xiaoxiao、yaoyao、yunyang），且语速控制存在一些限制：
1. 语音选项有限，无法满足用户多样化需求
2. 语速范围限制在 0.5-2.0 之间，可能不够灵活
3. 缺少对 Azure TTS 新增语音的支持

## What Changes
本次变更对Azure TTS插件进行以下主要改进：

1. **语音选项扩展**: 从原有的3个中文语音扩展到14个语音，包括xiaoyi、yunxi、yunxia、xiaochen、xiaohan、xiaomeng、xiaomo、xiaoxuan、xiaoyan、yaoyao、yunyang、yunye等
2. **语音配置优化**: 为每个语音添加中文显示名称、描述信息和适用场景分类
3. **语速控制验证**: 确保所有语音都支持0.5-2.0范围内的语速控制
4. **插件配置更新**: 更新JSON配置文件，包含所有新语音的详细信息
5. **API接口增强**: 更新/health端点返回完整的语音列表

## 目标
1. 扩展支持更多 Azure TTS 中文语音选项
2. 确保所有语音选项的语速控制（0.5-2.0）都能正常工作
3. 验证新语音的可用性和语速控制功能

## 范围
- 更新 Azure TTS 服务类，添加更多语音支持
- 验证语速控制在 0.5-2.0 范围内正常工作
- 更新插件配置文件，包含新的语音选项
- 更新文档和示例

## 风险与限制
- 需要验证新语音在 Azure TTS 服务中的可用性
- 需要测试每个语音的语速控制功能
- 语速超出 0.5-2.0 范围时使用默认值 1.0
