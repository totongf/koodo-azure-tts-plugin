# 适配 Koodo 速度参数映射

## Why (为什么需要这个变更)

当前 Azure TTS 插件在处理 Koodo 的速度参数时存在问题。根据 `Azure配置指南.md` 中的记录，Koodo 的速度参数需要按照特定公式映射为 Azure TTS 的语速参数：

**映射公式**: `Azure语速 = 1.0 + (Koodo速度参数 / 100)`

**具体问题**:
- Koodo 传递的速度参数直接传递给 Azure TTS，没有进行映射转换
- 用户在 Koodo 中设置的速度与实际语音效果不匹配
- 影响用户体验，降低语音合成的可用性

**解决需求**:
确保 Koodo 中的速度设置能够正确映射到 Azure TTS 的语速参数，让用户能够获得预期的语音播放效果。

## 变更描述

当前 Azure TTS 插件存在语速参数映射不正确的问题。Koodo 的速度参数需要按特定公式映射为 Azure TTS 的语速参数，确保用户在使用 Koodo 设置语速时，Azure TTS 能正确响应。

## What Changes
本次变更对Azure TTS插件进行以下主要改进：

1. **添加速度参数映射功能**: 在JavaScript插件中实现Koodo速度参数到Azure语速参数的映射转换
2. **映射公式实现**: 按照公式 `azure_rate = 1.0 + (koodo_speed / 100)` 进行转换
3. **参数验证和边界处理**: 确保映射后的参数在Azure TTS支持的0.5-2.0范围内
4. **日志记录增强**: 详细记录映射过程和参数变化
5. **错误处理机制**: 处理无效参数和超出范围值的情况

## 问题分析

### 当前状态
- 插件直接传递 Koodo 的 `rate` 参数给 Azure TTS 的 `e` 参数
- 没有进行必要的参数映射转换
- 用户体验与预期不符

### 期望状态  
- 实现 Koodo 速度参数到 Azure TTS 语速的正确映射
- 按照公式：`Azure语速 = 1.0 + (Koodo速度参数 / 100)`
- 确保参数范围在 Azure TTS 支持的 0.0-2.0 范围内

## 映射关系

根据 `Azure配置指南.md` 中的说明：

| Koodo 速度参数 | Azure 语速参数 | 实际效果 |
|---------------|---------------|----------|
| 0             | 1.0           | 基准语速 (100%) |
| 25            | 1.25          | 25% 加快语速 |
| -25           | 0.75          | 25% 减慢语速 |
| 50            | 1.5           | 50% 加快语速 |
| -50           | 0.5           | 50% 减慢语速 |
